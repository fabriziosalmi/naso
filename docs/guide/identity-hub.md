# Identity Hub

The NASO Identity Hub acts as a correlation matrix for user profiles extracted from breaches, social networks, and dark-web telemetry.

## Core Features
1. **Master Identity Merging**: If an email correlates with a username on an exposed platform, NASO automatically binds them into a generic Master Identity.
2. **Visual Investigation Navigation**: Force-directed network graphs dynamically render node clusters highlighting the intersections between victims, tactics (Mitre), and breach files.
3. **Automated Risk Scoring**: Identities gain severity modifiers based on the depth and breadth of the associated leaks.
