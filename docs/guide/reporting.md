# Reporting

NASO empowers analysts by making raw data readable through advanced Reporting features and AI-native distillation.

## Massive Dossier Export
Analysts can retrieve exhaustive PDF dossiers binding raw JSON metadata into court-ready documentation formats via automated formatting pipelines.

## Audit Tailing
NASO logs **every user-driven action** into a central audit trail (`/system/audit`), from launching dark-web probes to protecting identities. Reports provide transparency into organizational operation compliance.
